## أعطِ Navin مهمة

> «ابحث عن سبب هذا الخطأ، أصلحه، شغّل الاختبارات المناسبة واشرح التغييرات.»

> «ابحث عن هؤلاء المنافسين، قارن عروضهم مع ذكر المصادر، وأعدّ تقريرًا بالنتائج.»

> «راقب هذا المشروع وأخبرني عندما يظهر تغيير يحتاج إلى انتباهي.»

يربط Navin النموذج بملفاتك والطرفية والمتصفح وأدواتك. يستطيع التخطيط، وتوزيع مهام محددة على وكلاء فرعيين، والتحقق من النتائج ومواصلة العمل ضمن الحدود التي تضبطها.

**وما يتبقى بعد المحادثة مهم أيضًا:** معرفة المشروع، والقرارات، والمهارات القابلة لإعادة الاستخدام، وسياق العمل.

## ابدأ الآن

**Linux / macOS / WSL**

<div dir="ltr" align="left">

```bash
curl https://navin.live/install -fsS | bash
```

</div>

**Windows PowerShell**

<div dir="ltr" align="left">

```powershell
irm 'https://navin.live/install?win32=true' | iex
```

</div>

افتح الطرفية داخل مجلد مشروعك، ثم شغّل:

<div dir="ltr" align="left">

```bash
cd your-project
navin-cli
```

</div>

1. افتح **Settings** باستخدام **Ctrl+G** وأضف مفتاح API الخاص بك أو عنوان نموذج محلي.
2. اختر النموذج والوضع: **Ask** أو **Plan** أو **Agent** أو **Review** أو **Security** أو **Debug**.
3. جرّب: **«اقرأ هذا المشروع واشرح كيف يعمل، ثم اقترح تحسينًا مفيدًا.»**

تفضّل واجهة رسومية؟ [نزّل Navin Desktop لنظام Windows أو macOS أو Linux](https://navin.live/download).

البرنامج مجاني بموجب رخصته مفتوحة المصدر. قد تفرض واجهات النماذج والخدمات الخارجية رسوم استخدام. [التثبيت وحل المشكلات](./docs/Installation.md).

### التثبيت من المصدر (gateway + WebUI)

لتشغيل Navin أو تعديله على جهازك:

<div dir="ltr" align="left">

```bash
git clone https://github.com/Navinspire-ia/navin.git
cd navin
make install
make start
```

</div>

يثبّت `make install` حزم النظام الناقصة حيثما أمكن، ثم خلفية Python وواجهة WebUI. يشغّل `make start` البوابة وواجهة WebUI على [localhost:5173](http://localhost:5173).

إذا تجاوزت تثبيت حزم النظام (`NAVIN_SKIP_SYSTEM=1` أو `sh scripts/install.sh --no-system`)، ثبّت أولًا **Python 3.11+ وGit وMake وNode.js 18+ وnpm**.

على Linux/macOS، تحتاج بيئة العزل الأصلية أيضًا إلى **rustup** (`make native`).

لتشغيل CLI من المستودع: `.venv/bin/navin-cli`، أو `.venv\Scripts\navin-cli` على Windows. [دليل التثبيت الكامل](./docs/Installation.md).

## مساحة واحدة لأعمال متعددة

| هدفك | ما يقدمه Navin |
| --- | --- |
| **تطوير البرمجيات** | استكشاف المستودع، تعديل الشيفرة، الطرفية، Git، معاينة المتصفح، الاختبارات والمراجعة. |
| **فهم المشروع** | مخطط المشروع، فهرس الشيفرة، التعريفات والمراجع وتحليل أثر التغييرات. |

| **تنمية الأعمال** | العملاء المحتملون وإثراء بياناتهم، SEO، البحث التسويقي وإعداد الحملات. |
| **إنجاز المهام المهنية** | تحليل المناقصات، البحث عن فرص عمل، تفريغ الاجتماعات، الملاحظات والإجراءات. |

## ما الذي يستحق التجربة؟

**سياق يستمر بعد المحادثة.** تساعد ذاكرة المشروع ومخطط الشيفرة الوكيل على استرجاع القرارات والوصول إلى الملفات المناسبة. تضيف الذاكرة العرضية الاختيارية إمكانية استرجاع أعمال سابقة. [الذاكرة](./docs/memory.md) · [مخطط المشروع](./docs/navin_dev/en/graph.md)

**أدوات تصل التفكير بالتنفيذ.** ملفات وShell وGit ومتصفح وواجهات API وMCP. تجمع Skills أساليب عمل قابلة للتكرار، وتضيف الملحقات والتكاملات أدوات جديدة. [إعداد MCP](./docs/guides/configure-mcp-tools.md) · [المهارات](./navin/skills/README.md)

**أنت تختار النماذج.** استخدم OpenAI أو Anthropic أو Google أو Mistral أو DeepSeek أو Qwen وغيرها، أو نماذج محلية عبر Ollama وLM Studio وvLLM. يمكنك تخصيص نماذج مختلفة لمهام مختلفة. تتغير القدرات حسب النموذج والمزوّد. [الإعدادات](./docs/configuration.md)

**عمل مستمر بضوابط واضحة.** تتابع الحلقات الهدف، ويبحث Heartbeat عن المتابعات المفيدة. تحدّ الموافقات وميزانيات الموارد ونقاط الحفظ وأوامر الإيقاف من نطاق التنفيذ. [الأتمتة](./docs/automations.md) · [الأمان](./SECURITY.md)

يبقى مجلد العمل على جهازك عند التنفيذ المحلي. إذا اخترت نموذجًا بعيدًا أو خدمة متصلة، تُرسل البيانات اللازمة للطلب إلى تلك الخدمة.

## وكيل يستطيع التعلم من التجربة

يضم Navin آليات تعلم تجريبية تُفعّل اختياريًا:

| الآلية | ما تستكشفه |
| --- | --- |
| **Self-Evolve / Auto-Skills** | تحويل الإخفاقات المتكررة إلى مهارات مرشحة، وتقييمها ثم اعتمادها أو التراجع عنها. |
| **World model** | تعلم تنبؤات محلية لنتائج الأدوات من سجلات التنفيذ. |
| **Policy learning** | تقييم اقتراحات الإجراء التالي على حالات مخصصة للتقييم. |

هذه الآليات **معطلة افتراضيًا**. يخضع التفعيل لاختبارات، ويتطلب نشر مهارة لجميع المشاريع إجراءً بشريًا. لا تعيد هذه الآليات تدريب نموذج المحادثة.

الطموح هو تطوير وكلاء مستقلين أكثر قدرة. **لا يدّعي Navin أنه ذكاء اصطناعي عام (AGI).**

[تطور المهارات](./docs/skills-evolution.md) · [World model](./docs/world-model.md) · [Policy learning](./docs/policy.md)

## اربط أدواتك الحالية

- **النماذج:** مفاتيح API الخاصة بك أو استدلال محلي.
- **الإضافات:** خوادم MCP ومهارات وملحقات وأدوات مخصصة.
- **القنوات:** Telegram وSlack وDiscord وWhatsApp والبريد الإلكتروني وTeams وغيرها عبر التكاملات المهيأة.
- **الواجهات:** الطرفية وWebUI وتطبيقات سطح المكتب القابلة للتنزيل.

يضم مستودع GitHub المحرك العام للوكيل وCLI وWebUI والأدوات المرتبطة بها. تُدار حزم سطح المكتب وخدمة navin.live والبنية التحتية للموقع ونشر الإصدارات بشكل منفصل.
