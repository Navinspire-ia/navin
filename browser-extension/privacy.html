Confidentialité de Navin Import

Un script affiche la bulle Navin sur les pages HTTP et HTTPS autorisées. L'extension prépare une capture lorsque vous ouvrez le panneau ou cliquez sur « Relire la page ». Sur LinkedIn, elle reprend uniquement le texte que vous avez sélectionné. Sur les autres pages, elle peut lire le contenu affiché ou les fiches structurées de missions. Vous pouvez modifier et retirer les champs avant de les envoyer.

Les captures restent dans le stockage de session de l'extension jusqu'à leur envoi. Elles disparaissent à la fermeture du navigateur ; les anciennes captures sont aussi nettoyées lors d'une nouvelle capture. L'extension ne collecte ni les mots de passe ni les cookies des plateformes, et n'effectue pas de navigation automatique.

L'adresse de votre instance Navin et un jeton limité à l'analyse et aux imports sont conservés dans le stockage local de l'extension. Ce jeton permet de consulter les critères de matching, d'analyser les fiches et de les importer après validation. Il ne donne pas accès aux dossiers, comptes ou messages. Vous pouvez le révoquer depuis Navin ou déconnecter l'extension.

Le bouton d'analyse transmet les fiches capturées à votre Navin pour les comparer à vos critères Carrière. L'analyse ne les enregistre pas dans le vivier ou les opportunités. Elle peut signaler qu'une adresse source est déjà présente dans Navin, sans exposer le contenu de la fiche existante.

Après confirmation, les champs affichés, dont les coordonnées professionnelles éventuellement présentes, sont transmis uniquement à l'adresse Navin que vous avez configurée. HTTPS est requis hors de localhost et 127.0.0.1. Il n'y a ni télémétrie, ni publicité, ni envoi à un service d'enrichissement tiers.

Dans Navin, les fiches importées suivent la conservation des modules Carrière, Leads et Tender. Révoquer l'extension ne supprime pas ces fiches : leur suppression se fait dans le module concerné. Les coordonnées publiées ne constituent pas une vérification de l'email ni un consentement à la prospection.

Les règles des plateformes continuent de s'appliquer. Aucune absence de blocage ou de restriction du compte n'est garantie.
