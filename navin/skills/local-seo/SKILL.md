# Local SEO

Local ranking = relevance + distance + prominence. Influence relevance (profile + pages) and prominence (citations + reviews).

## When to use

- Businesses serving cities/regions (stores, clinics, agencies, restaurants)
- Multi-location rollouts

## When not to use

- Pure national/SaaS SEO with no local intent
- Fake locations or review generation schemes

## Pillars

| Pillar | Actions |
|--------|---------|
| Business profile | complete fields, categories, services, photos, weekly posts, Q&A |
| NAP consistency | identical Name/Address/Phone on site, profile, directories |
| Local pages | one page per city/service with local proof |
| Citations | industry + local directories, chamber |
| Reviews | steady flow, owner responses, natural keywords |
| Local schema | LocalBusiness JSON-LD with geo, hours, sameAs |

## Workflow

1. Audit: fetch local pages; check NAP strings; review GBP screenshots/exports the user provides.
2. Fix NAP mismatches first.
3. Build/refresh location pages: unique local substance, map, testimonials, FAQs.
4. Citation list: 15-25 relevant directories for the country (FR/DZ/Gulf as relevant) with claim/update status.
5. Review plan: post-service email + response templates for 1-5 stars.
6. Local keyword targets (city + service) via `keyword-research` qualitative method.
7. Save `seo/local-seo-<city>-<date>.md` + LocalBusiness JSON-LD draft.

## Rules

- Never create fake locations or fake reviews.
- Location pages need real local substance - see `programmatic-seo` anti-patterns.
- Distance cannot be faked; do not promise pack rankings.

## Anti-patterns

- Doorway city pages with spun paragraphs
- Inconsistent NAP across citations
