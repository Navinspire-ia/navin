# Local SEO

## Overview

Local ranking = relevance + distance + prominence. You can influence relevance (profile + pages) and prominence (citations + reviews).

## Pillars

| Pillar | Actions |
|--------|---------|
| Google Business Profile | complete every field, primary+secondary categories, services, photos, weekly posts, Q&A |
| NAP consistency | identical Name/Address/Phone everywhere (site, GBP, directories) |
| Local pages | one page per city/service with local proof (projects, clients, directions) |
| Citations | industry + local directories, chamber of commerce |
| Reviews | steady flow, owner responses to all, keywords appear naturally |
| Local schema | LocalBusiness JSON-LD with geo, hours, sameAs |

## Workflow

1. Audit current state: fetch the site's local pages, check NAP consistency, review GBP screenshots the user provides.
2. Fix NAP mismatches first — they undermine everything else.
3. Build/refresh location pages: unique content per location, embedded map, local testimonials.
4. Citation list: 15–25 relevant directories for the country (Algeria/France/Gulf as relevant).
5. Review generation plan: post-project email template + QR code, response templates for 1–5 star reviews.

## Rules

- Never create fake locations or fake reviews.
- Location pages must have real local substance — see `programmatic-seo` anti-patterns.
