# Backlink Strategy

## Overview

Links follow value. Plan assets worth linking to, then a realistic outreach list — no link farms, no PBNs.

## Opportunity types (by effort)

| Type | Effort | Examples |
|------|--------|----------|
| Existing relationships | Low | clients, partners, suppliers, associations |
| Directories / profiles | Low | industry directories, chambers, local listings |
| Unlinked mentions | Low | brand mentions found via search — ask for the link |
| Guest posts | Medium | niche blogs, industry media |
| Digital PR / data | High | original studies, benchmarks, free tools |

## Workflow

1. Inventory current links context: search `"domain.com" -site:domain.com` for existing mentions.
2. Mine competitors' sources (`competitor-seo-analysis`).
3. Propose 1–2 linkable assets (stat page, calculator, industry report).
4. Build a target list with contact angle for each (why *they* would link).
5. Draft outreach with `cold-email-writer` tone rules — personalized, short, value-first.

## Deliverable

```markdown
| Target site | Type | Contact angle | Asset to pitch | Priority |
```

## Rules

- Never propose buying links or automated spam.
- Anchor text diversity: mostly brand/natural, few exact-match.
- Track wins in `seo-monitoring`.
