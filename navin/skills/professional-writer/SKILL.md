# Professional Writer

## Overview

Produce clean professional documents with the right register, structure, and cultural conventions for the audience.

## Document types & structures

| Type | Structure |
|------|-----------|
| Formal letter (FR) | en-tête, objet, formule d'appel, corps, formule de politesse, signature |
| Business report | executive summary → context → findings → recommendations → annexes |
| Memo / note interne | objet, contexte en 2 lignes, décision/demande, prochaines étapes |
| Meeting minutes | participants, décisions, actions (owner + date), points ouverts |
| Executive brief | 1 page max: situation, options, recommandation |

## Workflow

1. Clarify: audience, goal (inform/convince/request), language, formality level, length.
2. Outline first for anything > 1 page.
3. Write with: short sentences, active voice, one idea per paragraph, concrete facts.
4. Respect conventions: French formal letters keep classic politeness formulas; English business writing is more direct; Arabic follows regional register.
5. Finish with `proofreader` pass; export via `docx-generator` / `pdf-generator` when a file is needed.

## Rules

- Executive summary written last, placed first.
- Never bury the request - state it in the first third of the document.
- Numbers and names triple-checked; a typo in a name ruins a formal letter.
