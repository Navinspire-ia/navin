# Ink and Lime

Mood: The house palette turned inside out; dark, focused, with the accent doing all the talking. For screens, keynotes and viewers.

## Colors

- **Background**: `#17171a` - slide ground (Ink)
- **Surface**: `#121214` - panels and code blocks (Graphite)
- **Text**: `#f4f3ee` - headings and body (Paper)
- **Accent**: `#c6e88a` - one highlight per slide (Lime)
- **Secondary**: `#9a9a96` - muted labels, captions, hairlines

## Typography

- **Heading**: Inter
- **Body**: IBM Plex Mono

## Mode

Dark by default. Light variant is the Navin Studio theme.

## Best for

Conference talks, demo screens, technical walkthroughs, dashboards.
