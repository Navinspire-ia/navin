# SEO Content Writer

## Overview

Write for the reader first; structure for search engines second. No stuffing, no filler intros, no "in today's fast-paced world".

## Article blueprint

1. **Title** — primary keyword near the front, ≤60 chars, promise clear value
2. **Meta description** — 140–155 chars, includes keyword + hook
3. **H1** — one only, close to the title
4. **Intro** — answer the query in the first 2–3 sentences (snippet-worthy)
5. **H2/H3 sections** — each answers a sub-question (use PAA themes)
6. **Internal links** — 2–5 to relevant pages with descriptive anchors
7. **Conclusion** — next action / CTA

## Workflow

1. Get the primary keyword + intent from `keyword-research` (or infer from the request).
2. Check top 3 SERP results with `web_fetch`: format, depth, what's missing.
3. Outline first; confirm with the user for long/high-stakes pieces.
4. Write with:
   - short paragraphs (2–4 lines), bullets, tables where scannable
   - concrete examples, numbers, named tools
   - primary keyword in title, H1, intro, one H2, conclusion — naturally
5. Run `proofreader` pass; verify claims with `fact-checker` habits.

## Rules

- Match the language and register of the target audience (FR/EN/AR).
- Never fabricate statistics or quotes — link real sources.
- Respect `brand-voice-manager` guidelines when defined.
