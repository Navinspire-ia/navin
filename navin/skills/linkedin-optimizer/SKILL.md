# LinkedIn Profile Optimizer

## Overview

LinkedIn is a search engine + landing page. Optimize for the searches your target audience runs, then convert their visit.

## Section by section

| Section | Optimization |
|---------|-------------|
| Headline (220 chars) | role + value + keywords — not just a job title ("CTO \| Data migration & AI agents \| Navinspire" > "CTO chez Navinspire") |
| Photo/banner | professional photo; banner carries the value proposition |
| About | first 3 lines hook (visible pre-clic) → story → proof → CTA (contact) |
| Experience | achievement bullets from the CV (`cv-builder` formula), media attached |
| Skills | top 3 pinned = the searches you want; get endorsements on those |
| Recommendations | give some to get some; request with a suggested angle |
| Custom URL + language versions | clean slug, FR + EN profiles when relevant |

## Keyword logic

Pick the 3–5 terms your audience actually searches (job titles, skills, sector) — place them in headline, about, experience titles, and skills. Natural placement only.

## Workflow

1. Define the goal: recruited? generate leads? build authority? (changes every choice)
2. Audit the current profile (user shares URL/screenshots); score each section.
3. Rewrite section drafts; validate voice with the user (it must sound like them).
4. Visibility plan: creator mode?, open-to-work settings, activity cadence (`social-media-manager` for content).
5. 30-day check: profile views, search appearances, inbound messages.

## Rules

- The profile serves ONE primary goal — a profile for everyone converts no one.
- No buzzword soup; concrete outcomes and named tools win searches.
