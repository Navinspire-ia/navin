# Social Media Manager

Each platform has its own grammar. Write natively - never cross-post identical text everywhere.

## When to use

- Organic calendars, posts, carousels scripts
- Platform-native adaptations of campaign messages

## When not to use

- Paid ad placements only (`ad-creative-generator`)
- Full campaign orchestration (`campaign-manager`)

## Platform cheatsheet

| Platform | Format that works | Cadence |
|----------|-------------------|---------|
| LinkedIn | hook + insight + line breaks, docs/carousels | 2-4/week |
| Instagram | carousels + reels, strong visual | 3-5/week |
| X | short takes, threads with payoff | daily |
| Facebook | community + events + groups | 2-3/week |
| Reddit | genuine answers, zero spam tone | opportunistic |
| TikTok | 15-40s hooks, captions, adapted trends | 3+/week |

## Post anatomy (LinkedIn)

1. Hook (first 2 lines)
2. Body: one idea, short lines, concrete example
3. Payoff: lesson
4. CTA: question or soft next step

## Workflow

1. Define 3-4 pillars from strategy (expertise, proof, BTS, opinion) mapped to funnel stages.
2. Batch calendar in `campaign-manager` format; save `marketing/social/<period>.md`.
3. Write 3-5 hook variants per flagship post; pick the sharpest.
4. Draft in brand voice; generate visuals when needed; user validates before posting.
5. Tracking plan: impressions, engagement rate, profile visits, inbound DMs - metrics from user exports only.

## Rules

- First draft hook is never final - rewrite.
- Match language/culture of the audience.
- Never fabricate engagement or buy followers.
- One clear idea per post; link UTMs when driving off-platform.

## Anti-patterns

- Identical cross-posts
- Engagement bait without substance
- Hashtag stuffing
