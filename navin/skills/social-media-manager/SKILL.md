# Social Media Manager

## Overview

Each platform has its own grammar. Write natively per platform — never cross-post the same text everywhere.

## Platform cheatsheet

| Platform | Format that works | Cadence |
|----------|-------------------|---------|
| LinkedIn | hook line + story/insight + line breaks, docs/carousels | 2–4/week |
| Instagram | carousels + reels, strong visual, caption hooks | 3–5/week |
| X | short takes, threads with payoff, replies to big accounts | daily |
| Facebook | community + events + groups | 2–3/week |
| Reddit | genuine answers in niche subs, zero self-promo tone | opportunistic |
| TikTok | 15–40s hooks, face + captions, trends adapted | 3+/week |

## Post anatomy (LinkedIn example)

1. Hook (first 2 lines decide everything — curiosity, number, contrarian take)
2. Body: one idea, short lines, concrete example
3. Payoff: lesson or takeaway
4. CTA: question or soft next step (no "follow me" begging)

## Workflow

1. Define 3–4 content pillars from strategy (expertise, proof/cases, behind-the-scenes, opinion).
2. Batch-produce a weekly/monthly calendar (`campaign-manager` format).
3. Recycle long-form via `content-recycler`.
4. Draft everything in the brand voice; user validates before posting.
5. Track: impressions, engagement rate, profile visits, inbound DMs — monthly review.

## Rules

- Hooks are rewritten 3–5 times; the first draft hook is never the best.
- Text in the platform's language and culture (FR for DZ/FR audience, EN for international).
- Never fabricate engagement or buy followers.
