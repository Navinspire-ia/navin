# Paid Ads Manager

## Overview

Paid ads amplify a working message — they don't fix a broken offer. Structure > hacks.

## Platform picker

| Platform | Best for | Minimum viable budget |
|----------|----------|----------------------|
| Google Search | existing demand (people searching the solution) | modest, intent-driven |
| LinkedIn | B2B targeting by title/industry/size | high CPC — tight ICP only |
| Meta (FB/IG) | B2C, local, retargeting, cheap reach | low, creative-hungry |

## Campaign structure

1. **Offer + landing page first** — validate with `conversion-rate-optimization`
2. Campaign → ad set/group per audience → 2–4 ad variants
3. Tracking before launch: conversion events, UTM, thank-you page
4. Budget: 70% proven / 30% test
5. Optimization cadence: no changes for the learning phase, then weekly cuts of losers

## Workflow

1. Define target CPA/CPL from unit economics (`marketing-analytics`).
2. Draft targeting + keywords/audiences + negative lists.
3. Write ad copy variants (hooks from `copywriting-agent`); design brief for visuals.
4. Launch checklist: pixel/tag firing, budget caps, geo/language settings.
5. Weekly report: spend, CPL, CTR, conversion rate per audience — kill/scale decisions.

## Rules

- Never launch without conversion tracking verified.
- One variable per ad test (hook, visual, or audience — not all three).
- Report honestly: platform-reported conversions vs actual pipeline.
