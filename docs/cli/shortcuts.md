# Shortcuts

These keys apply in `navin-cli`.

| Key | Action |
|---|---|
| Enter | Send |
| Shift+Enter | New line |
| Esc | Stop the running turn |
| Ctrl+P | Command palette |
| Ctrl+G | Settings |
| Ctrl+Y | Guardrails |
| Ctrl+K | Skills |
| Ctrl+E | Security |
| Ctrl+U | Tools & MCP |
| Ctrl+I | Provider settings |
| Ctrl+O | Model list |
| Ctrl+T | Mode list |
| Ctrl+S | Sessions |
| Ctrl+W | Workspace / project folder |
| Ctrl+B | Right panel |
| Ctrl+N | New chat |
| Ctrl+C / Cmd+C | Copy the selection (does not quit). Selecting text or right-click also copies it. |
| Ctrl+V / Cmd+V | Paste from the OS clipboard |
| Ctrl+Shift+C | Copy the last assistant reply |
| Ctrl+F | Find in the conversation |
| F2 | Graph |
| F3 | Evolve |
| F1 | Help |
| Ctrl+Q | Quit |

Full list: **F1** inside `navin-cli`.
