# Slash commands

Type `/` in `navin-cli`. **Ctrl+P** lists the same commands.

| Command | What it does |
|---|---|
| `/help` | List slash commands |
| `/new` | New chat |
| `/stop` | Cancel the running turn |
| `/status` | Runtime, provider, quota |
| `/model` | Show or switch the active model |
| `/history` | Last persisted messages |
| `/skill` | Enabled skills |

`/help` and `/status` answer immediately. Other slashes start a turn and need a configured model.
