# Marketplace Navin

First-party skills catalogue hosted on the Navin license site (navin.live or your org's configured host). Complements **ClawHub** (external public registry) with Navin-signed packages and an install ledger.

## Use Marketplace in the app

1. Open Navin → **Settings → Skills** (or the Skills area that includes **Marketplace**).
2. Browse featured skills from your configured site base URL (Account server URL, or `https://navin.live` by default).
3. Click **Install** on a skill. Navin records the install and adds the skill locally when package content is available.
4. Use ClawHub as the external option when Marketplace is unavailable.

If the catalogue route is not available on the configured site, the Marketplace panel shows a calm unavailable state and points you to ClawHub - it should not show a raw network error.

## What you see

- Featured, signed skill packages
- Version and changelog details when the site provides them
- Install into your local Navin skills set
