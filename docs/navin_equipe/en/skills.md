# Team skills

## Preloaded by `/team`

| Skill | Purpose |
| --- | --- |
| `org-designer` | Org structures from strategy: role sheets, RACI, rituals, scaling plans. **New, built for this module.** |
| `virtual-team-builder` | Composes and runs teams of AI subagents with roles, briefs, and orchestration patterns. **New, built for this module.** |
| `multi-agent-orchestration` | Coordination patterns for parallel and pipelined agents. |
| `task-planner` | Decomposing missions into tracked, ordered tasks. |
| `recruitment-agent` | End-to-end hiring workflows. |
| `job-description-writer` | Ready-to-publish job postings. |
| `candidate-screening` | Grid-based CV scoring and comparison. |
| `kpi-reporter` | KPI dashboards and review packs. |
| `human-approval` | Pausing for human sign-off on sensitive decisions. |

## Complementary skills

| Skill | Purpose |
| --- | --- |
| `interview-coach` | Interview preparation and mock sessions. |
| `career-advisor` | Career trajectory guidance for growth plans. |
| `ats-analyzer` | Matching CVs against role requirements. |
| `application-tracker` | Tracking hiring pipelines. |
| `meeting-followup` | Turning reviews and 1:1s into actions. |
| `professional-writer` | Polished internal documents and communications. |
| `spreadsheet-analyst` | Skills matrices, capacity models, headcount plans in Excel. |
| `pptx-generator` / `docx-generator` | Org decks and handbooks as real files. |
| `project-manager` | Project plans behind the staffing decisions. |
| `fact-checker` | Verifying market data used in compensation or benchmarks. |

Skills load automatically with `/team`; invoke any of them explicitly for a focused task ("use candidate-screening on these 12 CVs").
