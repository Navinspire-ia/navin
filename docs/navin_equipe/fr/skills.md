# Skills équipe

## Préchargés par `/team`

| Skill | Rôle |
| --- | --- |
| `org-designer` | Structures d'org depuis la stratégie : fiches de rôle, RACI, rituels, plans de croissance. **Nouveau, conçu pour ce module.** |
| `virtual-team-builder` | Compose et pilote des équipes de subagents IA avec rôles, briefs et patterns d'orchestration. **Nouveau, conçu pour ce module.** |
| `multi-agent-orchestration` | Patterns de coordination pour agents en parallèle ou en pipeline. |
| `task-planner` | Décomposition des missions en tâches ordonnées et suivies. |
| `recruitment-agent` | Workflows de recrutement de bout en bout. |
| `job-description-writer` | Fiches de poste prêtes à publier. |
| `candidate-screening` | Notation de CV sur grille et comparaison. |
| `kpi-reporter` | Dashboards KPI et packs de revue. |
| `human-approval` | Pause pour validation humaine sur les décisions sensibles. |

## Skills complémentaires

| Skill | Rôle |
| --- | --- |
| `interview-coach` | Préparation d'entretiens et sessions blanches. |
| `career-advisor` | Conseil de trajectoire pour les plans de progression. |
| `ats-analyzer` | Matching CV / exigences du poste. |
| `application-tracker` | Suivi des pipelines de recrutement. |
| `meeting-followup` | Transformer revues et 1:1 en actions. |
| `professional-writer` | Documents internes et communications soignés. |
| `spreadsheet-analyst` | Matrices de compétences, modèles de capacité, plans d'effectif en Excel. |
| `pptx-generator` / `docx-generator` | Decks d'org et manuels en vrais fichiers. |
| `project-manager` | Plans projet derrière les décisions de staffing. |
| `fact-checker` | Vérification des données marché (rémunération, benchmarks). |

Les skills se chargent automatiquement avec `/team` ; invoquez-en un explicitement pour une tâche ciblée (« utilise candidate-screening sur ces 12 CV »).
