# Templates - 50 models, 6 groups

Each card sends `/studio` with a precise specification. Your optional brief is appended to every one. An output language must be selected explicitly before any generation.

## Project

| Template | Format | Generates |
| --- | --- | --- |
| Project pitch deck | PPTX | 10-12 slides: vision, problem, solution, approach, timeline, team, risks, next steps. Strong visual hierarchy, one idea per slide. |
| Project charter | DOCX | Context, SMART objectives, scope in/out, stakeholders and roles, governance, milestones, budget summary, risks and mitigations. |
| Roadmap & planning | XLSX | Phases, workstreams, tasks with owners, start/end dates, dependencies, milestone sheet, status dashboard with conditional formatting. |
| Status report | PDF | One page: overall RAG status, progress vs plan, key metrics, accomplishments, blockers, decisions needed, next period plan. |
| Project budget | XLSX | Cost breakdown by category, forecast vs actual with variance, monthly burn rate chart data, summary sheet. |

## Legal - 25 contracts

These internationally neutral templates do not choose the law for you. Governing law and the dispute forum are configurable. The agent adapts and translates the complete HTML source, checks consistency across parties, definitions, dates, obligations, cross-references, annexes and signatures, and retains that HTML with the DOCX or PDF export. Every generated contract must be reviewed by qualified counsel in the relevant jurisdiction before signature.

## Language and localization

- Language is mandatory and is never inferred from the interface or template.
- Labels, metadata, dates, numbers and currencies remain in the selected language and locale from source through export.
- Arabic and other RTL languages use RTL direction, logical reading order, mirrored layout when appropriate and fonts with Arabic glyph coverage.
- CSV files use UTF-8; the locale-appropriate delimiter is announced with the deliverable.
