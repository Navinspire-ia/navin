# SEO actions - 12 cards

Each card sends `/seo` with a precise specification; your brief is appended.

## Audit

| Action | Delivers |
| --- | --- |
| Technical audit | Bounded site crawl: records status, redirects, robots, sitemaps, canonicals, hreflang, meta and headings, validates JSON-LD, maps internal links, and uses PSI/CrUX only with measured API data - deterministic health score and evidence-backed findings. |
| On-page audit (URL) | Deep audit of one page: title/meta/H-structure, keyword targeting and intent match, content depth vs top competitors, internal links, media optimization - prioritized fix list with rewritten elements. |
| Competitor analysis | Fetches competitors' key pages, compares content strategy, site structure, targeted keywords, and strengths - gap analysis with concrete opportunities. |
| Content audit | Inventories the site's main pages, flags thin or outdated content, detects keyword cannibalization - keep/refresh/merge/delete action plan. |

## Research

| Action | Delivers |
| --- | --- |
| Keyword research | Seed expansion, intent classification (informational/commercial/transactional), difficulty and value estimates, clustered and prioritized in a table saved as a file. |
| Content plan & clusters | Pillar pages and supporting articles per cluster, target keyword and intent for each, internal linking plan, publishing order by impact. |
| Questions & intents | Questions users ask (people-also-ask style, forums, related searches), listed by intent, mapped to content formats, with quick wins highlighted. |
| Local SEO | Business profile optimization checklist, local keyword targets, citations and reviews strategy, localized landing page structure, tracking plan. |

## Optimize

| Action | Delivers |
| --- | --- |
| SEO article | Complete optimized article: title tag and meta description, H1-H3 structure covering the topic's entities, natural keyword usage, FAQ section, internal link suggestions, schema.org FAQPage/Article markup - saved as a file. |
| Meta & tags optimization | Rewritten title tags (CTR-focused, correct length), meta descriptions, Open Graph/Twitter tags, heading hierarchy - before/after tables. |
| Schema.org markup | JSON-LD structured data adapted to the site: Organization, Product, Article, FAQ, Breadcrumb, or LocalBusiness - valid, ready to paste, with placement instructions. |
| Links & backlinks plan | Internal linking plan (money pages, anchors, mesh between clusters) plus a backlink acquisition plan (targets, tactics, outreach templates), prioritized by effort/impact. |
