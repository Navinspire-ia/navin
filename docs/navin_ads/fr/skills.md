# Skills Ads

## Préchargés par `/ads`

| Skill | Rôle |
| --- | --- |
| `studio-expert-contract` | Contrat bureau senior : preuves, livrables, gate PASS/WARN/BLOCK. |
| `critic-reviewer` | Revue critique avant livraison. |
| `paid-ads-manager` | Choix plateforme, structure, tracking, kill/scale ; préfère MCP live. |
| `marketing-analytics` | Unit economics, cibles CPA/CPL, honnêteté des mesures. |
| `conversion-rate-optimization` | Landing/offre prêtes avant le spend. |
| `copywriting-agent` | Hooks et variantes de copy. |
| `ad-creative-generator` | Concepts créatifs et notes de placement. |
| `project-board` | Plan tracké avec evidence avant done. |
| `studio-html-report` | Rapport `ads-report-*.html` + File Preview. |

## Presets MCP (Réglages → MCP, catégorie ads)

| Preset | Rôle |
| --- | --- |
| `google-ads` | MCP officiel Google Ads (pipx). |
| `meta-ads` | MCP hébergé Meta `https://mcp.facebook.com/ads`. |
| `tiktok-ads` | MCP communauté TikTok Ads via uvx. |
| `reddit-ads` | MCP Reddit Ads API v3 (lecture seule par défaut). |
| `linkedin-ads` | Comptes, campagnes et rapports LinkedIn Ads (jeton Marketing API). |

## Skills complémentaires

| Skill | Rôle |
| --- | --- |
| `campaign-manager` | Brief / message house (studio Marketing). |
| `brand-voice-manager` | Voix de marque sur les créas. |
| `image-generation` / `video-generation` | Production d'assets (studio Marketing). |
| `fact-checker` | Vérif des claims avant publication. |

Pour les créas et brand kits, ouvrez **Marketing** (`/campaign`). Pour les comptes live, restez dans **Ads** (`/ads`).
