# Ads skills

## Preloaded by `/ads`

| Skill | Purpose |
| --- | --- |
| `studio-expert-contract` | Senior desk contract: evidence, deliverables, PASS/WARN/BLOCK gate. |
| `critic-reviewer` | Critical review before delivery. |
| `paid-ads-manager` | Platform picker, structure, tracking, weekly kill/scale; prefers live MCP. |
| `marketing-analytics` | Unit economics, CPA/CPL targets, measurement honesty. |
| `conversion-rate-optimization` | Landing/offer readiness before spend. |
| `copywriting-agent` | Ad hooks and copy variants. |
| `ad-creative-generator` | Creative concepts and placement notes. |
| `project-board` | Tracked plan with evidence before done (injected for tracked workflows). |
| `studio-html-report` | Polished `ads-report-*.html` + File Preview (injected for HTML workflows). |

## MCP presets (Settings → MCP, category ads)

| Preset | Role |
| --- | --- |
| `google-ads` | Official Google Ads MCP (pipx). |
| `meta-ads` | Meta-hosted MCP at `https://mcp.facebook.com/ads`. |
| `tiktok-ads` | Community TikTok Ads MCP via uvx. |
| `reddit-ads` | Reddit Ads API v3 MCP (read-only default). |
| `linkedin-ads` | LinkedIn Ads accounts, campaigns, and reports (Marketing API token). |

## Complementary skills

| Skill | Purpose |
| --- | --- |
| `campaign-manager` | Broader campaign brief / message house (Marketing studio). |
| `brand-voice-manager` | Voice consistency across creatives. |
| `image-generation` / `video-generation` | Asset production (Marketing studio). |
| `fact-checker` | Claims check before publishing ads copy. |

For creatives and brand kits, open **Marketing** (`/campaign`). For live account ops, stay in **Ads** (`/ads`).
