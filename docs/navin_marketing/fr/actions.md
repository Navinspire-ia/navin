# Actions marketing — 12 cartes

Chaque carte envoie `/campaign` avec une spécification précise ; votre brief y est joint.

## Créatif

| Action | Livre |
| --- | --- |
| Images produit | Visuels produit professionnels : packshot studio, scène lifestyle, variantes prêtes pour les réseaux — générés avec les outils image, 3 directions visuelles proposées d'abord. |
| Vidéo publicitaire | Vidéo pub complète : script 15-30 s construit sur une accroche, storyboard scène par scène avec descriptions de plans et textes à l'écran, voix off, puis la vidéo générée quand un provider vidéo est configuré. |
| Visuels réseaux sociaux | Jeu d'images de marque : variantes carré (feed), vertical (couverture story/reel) et paysage (post lien) avec un branding cohérent. |
| Kit de marque | 3 pistes de concept de logo (générées), palette de couleurs avec codes hex, association typographique, guide de ton, exemples d'usage. |

## Contenu

| Action | Livre |
| --- | --- |
| Posts réseaux sociaux | Un lot de posts adaptés par plateforme (LinkedIn, X, Instagram, script TikTok) : accroches fortes, ton natif, hashtags, CTA, heure de publication suggérée. |
| Article de blog | Options de titres, plan H2/H3, intro engageante, corps actionnable avec exemples, conclusion avec CTA, plus meta description et 3 extraits de promo. |
| Séquence email | 5 emails (nurture ou lancement) : objets en variantes A/B, preview text, corps persuasif avec un CTA chacun, timing d'envoi recommandé. |
| Copy landing page | Variantes de titre/sous-titre hero, blocs bénéfices, section preuve sociale, FAQ anti-objections, copy de CTA — section par section. |

## Stratégie

| Action | Livre |
| --- | --- |
| Campagne 360° | Le tout-en-un : message clé et concept créatif, plan par canal, puis chaque livrable (copies, posts, visuels, script vidéo, email, landing) généré et enregistré, avec tableau récapitulatif final. |
| Persona client | Personas détaillés : démographie, objectifs, douleurs, objections, déclencheurs d'achat, canaux préférés, angles de message — documentés avec les outils web si utile. |
| Plan de contenu 30 jours | Thèmes hebdomadaires, un post par jour avec canal/format/accroche/CTA, aligné sur les étapes du funnel — livré en tableau structuré et enregistré en fichier. |
| Analyse concurrentielle | Positionnement, messages, canaux, stratégie de contenu et offres des concurrents — récupérés depuis leurs pages publiques, avec tableau comparatif et angles de différenciation. |
