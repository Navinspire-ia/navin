# Skills marketing

## Préchargés par `/campaign`

| Skill | Rôle |
| --- | --- |
| `campaign-manager` | Orchestre les campagnes de bout en bout : message, canaux, livrables, calendrier. |
| `ad-creative-generator` | Concepts publicitaires, accroches et variations créatives. |
| `social-media-manager` | Contenu natif par plateforme, formats et stratégie de publication. |
| `copywriting-agent` | Copies persuasives : titres, corps, CTA. |
| `image-generation` | Génère des images via le provider configuré. |
| `video-generation` | Scripts, storyboards et génération vidéo via le provider configuré. |
| `brand-voice-manager` | Maintient une voix cohérente sur tous les assets. |
| `customer-persona-builder` | Construit des personas documentés. |

## Skills complémentaires

| Skill | Rôle |
| --- | --- |
| `digital-marketing` / `growth-marketing` | Playbooks par canal et boucles de croissance. |
| `marketing-strategist` | Positionnement et stratégie go-to-market. |
| `marketing-analytics` | Mesure de la performance des campagnes. |
| `market-research` | Taille de marché, tendances et insights. |
| `paid-ads-manager` | Structure et optimisation des campagnes payantes. |
| `email-marketing` | Séquences, délivrabilité et automatisation. |
| `content-generation` / `content-recycler` | Production et recyclage de contenu à l'échelle. |
| `blog-writer` | Articles longs. |
| `product-visuals` | Direction et génération de visuels produit. |
| `go-to-market-planner` | Plans de lancement. |
| `conversion-rate-optimization` | Optimisation des landings et du funnel. |
| `lead-generation` / `lead-qualification` | Acquisition et scoring de leads. |
| `competitor-intelligence` | Veille concurrentielle. |
| `cold-email-writer` / `email-writer` | Copies d'emails outbound et transactionnels. |
| `fact-checker` / `proofreader` | Passe qualité avant publication. |

Les skills se chargent automatiquement avec `/campaign` ; invoquez-en explicitement pour une tâche ciblée (« utilise paid-ads-manager pour structurer la campagne Google Ads »).
