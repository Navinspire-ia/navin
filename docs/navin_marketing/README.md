# Navin Marketing - Documentation

Documentation for the **Marketing Agent OS** (`#/marketing`): local brand book, campaigns, content, creatives, visual QA, and an autonomous growth loop. Same store as Studio, Tauri, `navin marketing`, `python -m navin.marketing.desk_cli`, and the `marketing` tool.

Documentation du **Marketing Agent OS** (`#/marketing`) : livre de marque local, campagnes, contenus, creatives, QA visuel, et une boucle de croissance autonome. Meme store que Studio, Tauri, `navin marketing`, `python -m navin.marketing.desk_cli` et l'outil `marketing`.

The loop measures then improves on a saved wall-clock calendar. Heartbeat only watches. The desk never publishes and never spends ad budget.

La boucle mesure puis ameliore sur un calendrier mural. Le heartbeat ne fait que surveiller. Le desk ne publie jamais et ne depense jamais de budget ads.
