# Tenders skills

## Preloaded by `/tenders` and the module

| Skill | Role |
| --- | --- |
| `tender-agent` | Desk contract: official collect, score, GO/NO-GO, write, loop. Never invent a notice. Write must reuse on-file extracts. |
| `tender-monitor` | Watch: follow / watch. No collect or write from heartbeat. |
| `rfp-writer` | Matrix, requirement mapping, structured RFP / RFQ / DAO answers **after** `write`. |
| `proposal-writer` / `sales-proposal-writer` | Expand a commercial offer on on-file facts. |
| `contract-reviewer` | Clause / risk reading. |
| `critic-reviewer` | Review before delivery. |
| `scrape-operator` / `scrapling` | Public listing Collect missed. Never a login wall. |
| `web-extractor` | Structured extract from a public notice page. |

## Complementary

| Item | Role |
| --- | --- |
| `docx-generator` / `pptx-generator` / `pdf-generator` | Submission file **after** the write draft. |
| `pdf-ocr-extractor` | Scanned CDC with no text layer. |
| Notes | Knowledge outside the desk. Write reads the Tenders store, not Notes. |
| LinkedIn MCP | Buyer research (user session). Never invent a notice from a post. |
| Exa MCP | Public research on official hosts. |

Skills and write must cite `source_url`. Default send mode is **approval**.
