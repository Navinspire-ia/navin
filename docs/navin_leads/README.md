# Navin Leads & Sales - Documentation

Documentation for the **Leads** module (`#/leads`): a local-first GTM desk - open-data hunt, BANT-F scoring, buying signals, prepared outreach, and a Start loop that matches Career / Tenders / Trading. Same store as Tauri (Linux, Windows, macOS), `navin leads`, and the `leads` agent tool.
