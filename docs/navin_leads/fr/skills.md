# Skills leads & ventes

## Préchargés par `/leads`

| Skill | Rôle |
| --- | --- |
| `lead-prospector` | Chasse experte d'entreprises/personnes/contacts depuis les sources ouvertes, sortie entièrement sourcée. **Nouveau, créé pour ce module.** |
| `buying-signals` | Détecte et score les signaux levées, recrutement, changements tech et direction ; associe chaque signal à un angle d'approche. **Nouveau, créé pour ce module.** |
| `lead-generation` | Construction de listes de prospects basées sur l'ICP. |
| `lead-qualification` | Scoring BANT-F et paliers. |
| `account-research` | Fiches comptes avant rendez-vous. |
| `entity-research` | Recherche approfondie sur une entreprise ou une personne. |
| `outreach-sequencer` | Séquences multi-touches et multicanales. |
| `cold-email-writer` | Emails sortants qui obtiennent des réponses. |
| `customer-persona-builder` | Personas du comité d'achat. |
| `pipeline-analyst` | Santé du pipeline et forecasts pondérés. |

## Skills complémentaires

| Skill | Rôle |
| --- | --- |
| `crm-update-agent` | Pousser leads et activités dans HubSpot/Salesforce ou des fichiers. |
| `discovery-call-assistant` | Assistance en direct pour les appels de découverte. |
| `objection-handler` | Playbooks AER et battlecards. |
| `meeting-followup` | Synthèses post-rendez-vous et prochaines étapes. |
| `pricing-assistant` | Scénarios de prix et planchers. |
| `sales-proposal-writer` / `proposal-writer` | Propositions prêtes pour le client. |
| `contract-reviewer` / `contract-extractor` | Risques de clauses et extraction structurée. |
| `tender-monitor` | Veille d'appels d'offres. |
| `competitor-intelligence` | Veille concurrentielle. |
| `deep-web-research` / `web-extractor` | Recherche multi-sources et extraction structurée de pages. |
| `linkedin-optimizer` | Optimisation de profil pour le social selling. |
| `fact-checker` | Vérification des affirmations avant l'outreach. |

Les skills se chargent automatiquement avec `/leads` ; invoquez-en explicitement pour une tâche ciblée (« utilise pipeline-analyst sur les deals du trimestre »).
