# Meeting actions

Actions available from the Meeting desk (`#/meeting`, `/meeting`).

| Action | What it does |
| --- | --- |
| Minutes | Template-driven CR with decisions and owned actions |
| Executive summary | Short stakeholder summary (template-aware) |
| Identify speakers | Label Speaker 1/2… or explicit names only |
| Follow-up email | External email draft (human sends) |
| Action list | Owner + deadline table with evidence quotes |
| High-accuracy pass | Clean obvious ASR errors; regenerate summary |
| Visual recap | Recap image plus a decision diagram inside the HTML report |
| Discovery digest | Sales discovery notes via discovery-call-assistant |
| Chat with meeting | Ask grounded questions about this meeting only |
| Export Markdown | Instant local download |
| Export DOCX / PDF | Seed document/report generation |
| Calendar ICS | Import/link events; local start notification |
| Audit trail | Local GDPR-oriented action log export |
