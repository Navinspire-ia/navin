# Meeting skills

Used by the Meeting studio (`#/meeting`, command `/meeting`).

| Skill | Role |
| --- | --- |
| `meeting-studio` | Desk workflow, templates, speakers, chat, exports, report gate |
| `meeting-followup` | Minutes, follow-up email, CRM hygiene |
| `discovery-call-assistant` | Discovery / sales call digest |
| `studio-expert-contract` | Expert quality contract |
| `critic-reviewer` | PASS/WARN/BLOCK review |
| `crm-update-agent` | Optional CRM activity notes (explicit approval) |
| `studio-html-report` | `meeting-report-*.html` delivery (PDF via File Preview) |

STT uses the provider configured under Settings -> Voice. Prefer your highest-accuracy managed or local model for professional capture.
