# Navin Meeting - Documentation

Documentation for the **Meeting** studio (`#/meeting`, command `/meeting`): local capture, transcription through **your** providers, template-driven minutes, speaker labeling, ICS calendar with join links, Markdown / DOCX / PDF exports, and a local audit trail.
