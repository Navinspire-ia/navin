# Actions RiskLens - 9 cartes

Chaque carte envoie `/risklens` avec une spécification précise ; votre brief y est joint. Aucune action ne démarre l'implémentation du projet.

## Lancer

| Action | Livre |
| --- | --- |
| RiskLens complet | Session complète : contexte minimum, cadre d'échec à 6 mois, raisons d'échec, deep-dives parallèles, synthèse (échec le plus probable / le plus dangereux, hypothèse cachée, plan révisé, checklist 3-5 items), fichiers `risklens-report-*.html` et `risklens-transcript-*.md`. |
| Lancement produit / feature | RiskLens orienté produit avant tout code : décalage d'audience, friction d'adoption, dérive de scope, timing concurrentiel, métrique de succès atteignable. Rapport + plan révisé + checklist. |
| Lancement go-to-market | RiskLens de lancement où l'enjeu (argent / réputation) est fort : friction d'approbation pricing, portée des canaux, adéquation message-marché, temps de prep vs coût d'opportunité, risques composés post-lancement. |

## Décisions

| Action | Livre |
| --- | --- |
| Embauche ou rôle | Pourquoi ce recrutement échoue avant l'offre : ambiguïté de rôle, mauvaise séniorité, fit culturel, temps de montée en charge, problème d'org déguisé en hire. Brief de rôle révisé + checklist pré-offre. |
| Pricing / modèle économique | Ce qui casse si le changement de prix ou de modèle échoue : willingness to pay, chaînes d'approbation, cannibalisation, unit economics, coûts de switching. Plan de test (prix / cohorte pilote) + checklist go/no-go. |
| Partenariat ou deal | Pourquoi le partenariat meurt après la poignée de main : incentives mal alignés, ownership flou, dépendance, risque de réputation, termes de sortie. Garde-fous de deal révisés + checklist pré-signature. |
| Pivot stratégique | Angles morts d'un changement de positionnement ou de stratégie : gaps de capacité, confusion de marque, accès aux canaux, réponse concurrentielle, critères de succès mesurables. Stratégie révisée + signaux d'alerte + checklist pré-engagement. |

## Focus

| Action | Livre |
| --- | --- |
| Hypothèses cachées | RiskLens centré sur l'hypothèse la plus dangereuse non questionnée, puis signaux d'alerte et plus petite expérience qui la falsifierait cette semaine. Fichiers de rapport inclus. |
| Checklist pré-lancement seule | RiskLens concentré sur 3-5 actions vérifiables qui préviennent ou détectent les modes d'échec principaux, avec une synthèse courte (échec le plus probable + hypothèse cachée). |
