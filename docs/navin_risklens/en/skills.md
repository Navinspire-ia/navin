# RiskLens skills

## Preloaded by `/risklens`

| Skill | Purpose |
| --- | --- |
| `risklens` | Full method: context threshold, "already failed" frame, raw reasons, deep-dives, synthesis, HTML/MD reports. |
| `multi-agent-orchestration` | Subagent orchestration (`spawn`) - one investigator per failure reason, in parallel. |
| `task-planner` | Clear step breakdown and done criteria for the session. |

## Complementary skills

| Skill | Purpose |
| --- | --- |
| `customer-persona-builder` | Clarify the audience when the brief is fuzzy (often a failure source). |
| `competitor-intelligence` | Ground competitive scenarios in public facts. |
| `deep-web-research` | Multi-source research to validate or falsify assumptions. |
| `project-board` | Turn the revised plan / checklist into trackable tasks before Code. |
| `document-templates` | Formalize the revised plan as a deck or memo via the Documents module. |

Skills load automatically with `/risklens`. Invoke extras explicitly for a focused pass ("use customer-persona-builder before RiskLens").
